# Trocas Mamalonas — Giveaway Draw

## Running a draw
1. Upload the entries .txt (one entry per line, duplicates = extra tickets)
2. Press START THE DRAW, Space, or R
3. REDRAW for a fresh draw · NEXT WINNER for 2nd/3rd place · CLOSE to clear

## Shortcuts
Space / R — draw   ·   F — fullscreen   ·   Esc — reset to ready

## Settings (gear icon)
Presets, burst length + intensity + ramp, cruise speed, slowdown length + feel,
countdown, near-miss tease, exclude previous winners, result lock, fonts, rows,
text size, pill width/roundness/glow, shine speed, colors, background image or
video with overlay, sound, cursor hiding, settings export/import, admin PIN.

## Updating
Edit `src/App.jsx` on GitHub and commit — Vercel redeploys automatically.
